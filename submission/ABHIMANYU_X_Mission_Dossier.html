NOVELTY 1
AI Does Not Self-Certify

Conventional AI repair: Code → LLM → Patch → Done. ABHIMANYU X: Code → Evidence → LLM → Patch → Independent verification → PASS? NO → retry; YES → Memory.

NOVELTY 2
Evidence Bundle

The LLM isn't operating in isolation. It receives: Git Diff + Static Finding + Crash + ASan + Stack + Reproduction + Relevant Source. Evidence-grounded security reasoning rather than generic code completion.

NOVELTY 3
Closed-Loop Repair

PATCH #1 → VERIFY → FAIL → FAILURE EVIDENCE → ANVIL → PATCH #2 → VERIFY. Autonomous repair loop with bounded retries.

NOVELTY 4
Adversarial Patch Verification

Also test: Original exploit + Boundary variations + Malformed inputs + Regression cases + Sanitizers + Normal behaviour. Reduces the risk of a patch that merely suppresses the original symptom.

NOVELTY 5
Immune Memory

Normal security scanner: Vulnerability → Report. ABHIMANYU X: Vulnerability → Root Cause → Verified Repair → Pattern → Immune Memory → Future Target.

NOVELTY 6
